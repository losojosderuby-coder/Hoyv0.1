HOY — actualización de carpetas v5

CAMBIOS INCLUIDOS
1. Dentro de una carpeta aparece un botón visible «← Todas las misiones» para regresar a la vista general del proyecto.
2. Al seleccionar una o varias misiones, aparece inmediatamente la acción «Mover ... seleccionadas a carpeta».
3. Cuando se está dentro de una carpeta, al seleccionar misiones aparece también «Quitar de esta carpeta».
4. Quitar una misión de una carpeta la devuelve a «Todas las misiones»; no elimina la misión ni sus tareas, descripción, prioridad o historial.
5. Mover varias misiones permite elegir otra carpeta o «Sin carpeta».
6. Se mantienen las carpetas compactas, la edición de carpetas y la acción de mover una misión desde su detalle.
7. Se conserva la estructura de archivos en la raíz para GitHub Pages y la clave de almacenamiento local existente `hoy-data-v1`.

PUBLICACIÓN
1. Hacer una copia de seguridad desde HOY antes de actualizar.
2. Extraer todos los archivos directamente en la raíz del repositorio GitHub Pages, reemplazando los archivos de la versión anterior. No subir la carpeta contenedora.
3. No borrar los datos del navegador ni limpiar el almacenamiento del sitio.
4. El service worker usa la caché `hoy-cache-v18` para que el navegador descargue esta versión nueva.
