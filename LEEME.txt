HOY v0.4 — Estructura por misiones

Incluye:
- Navegación Núcleo → Proyecto → Misión → Tareas.
- Tarjetas visuales para proyectos y misiones, listas para tareas.
- Sesiones registradas dentro de cada misión o proyecto.
- Autoguardado de borradores de sesión.
- Conserva los proyectos y tareas anteriores; las tareas viejas quedan visibles como “sin misión”.
- Mantiene el mismo almacenamiento local y la misma dirección de GitHub Pages.

Instalación:
1. En el repositorio Hoyv0.1, reemplazá index.html y sw.js por estos archivos.
2. No reemplaces manifest.webmanifest.
3. Commit changes y esperá unos segundos.
4. Abrí la misma dirección de HOY y recargá la página.

Antes de instalar, ya exportaste una copia de tus datos. No borres los datos del sitio en Safari.
